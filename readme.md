A modern, interactive restaurant website featuring menu browsing, favorites, cart management, and table reservations.

## ✨ Features

- **Image Gallery** - Browse sushi selections with interactive heart icons to mark favorites
- **Food Menu** - Detailed menu with descriptions and "Add to Cart" functionality
- **Shopping Cart** - View and manage selected items with overlay interface
- **Reservations** - Book tables with time-slot validation to prevent double bookings
- **Responsive Design** - Mobile-friendly layout with clean navigation

## 📁 Project Structure

```
├── index.html          # Homepage with gallery and about section
├── food.html           # Menu page with food items and cart
├── reservations.html   # Reservation booking form
├── index.js            # All JavaScript functionality
├── styles.css          # Complete styling
└── images/             # Restaurant and food images
```

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Browse the menu, add items to cart, or make a reservation
3. No build process or dependencies required

## 💻 Technologies

Pure HTML, CSS, and JavaScript - no frameworks needed.
Learning front end - Proof of concept project for learing frontend
